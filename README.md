# Bank Marketing Prediction System

## Project Overview

This is an End-to-End Machine Learning project
that predicts whether a customer will subscribe
to a bank term deposit.

## Problem Statement

Banks conduct marketing campaigns to attract
customers.

However, contacting every customer is expensive.

This project uses Machine Learning to predict
which customers are more likely to subscribe.
